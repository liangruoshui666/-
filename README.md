# 小王子的星际画室

一个可交互的《小王子》主题星际画布。拖动旋转场景，点击角色或行星查看故事，使用星迹画笔绘画并保存 PNG。

## 部署到 Render

点击下方按钮，在 Render 中确认创建公开静态站点。源码仓库保持私有；Render 需要获得此仓库的读取权限。

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/liangruoshui666/-)

Render 会读取根目录的 `render.yaml`，并将根目录作为静态文件目录发布。

## 本地预览

直接用浏览器打开 `index.html` 即可。
